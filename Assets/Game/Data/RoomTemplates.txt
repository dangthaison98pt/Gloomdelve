# Gloomdelve room templates. Each room is 10 wide x 8 tall. Row 0 = top.
# Header: [name] types=<room types> tags=<start|exit|shop|idol|vault> areas=<1,2> weight=<n>
# Room types: 0 side (off the path), 1 left+right, 2 left+right+bottom, 3 left+right+top, 4 all sides.
# Conventions that keep rooms connectable:
#   * L/R rooms keep columns 0 and 9 open on rows 4-6 with floor on row 7.
#   * Bottom exits (type 2/4) are a hole on row 7 that includes columns 4-5.
#   * Top exits (type 3/4) open row 0 on columns 3-6; type 4 must break the fall (ledge or platform on rows 3-5).
# Legend: . empty   # dirt   X bedrock   ? 55% dirt   = wooden platform   H ladder   $ gold vein
#         ^ spikes slot   A arrow-trap slot   v ceiling hazard slot (stalactite / crusher)   f flame-vent slot
#         T treasure   E ground enemy   B ceiling enemy   I item (rock/pot/crate)   D door   O idol altar
#         K shopkeeper   S shop item   % cracked rubble (bomb gate)   R rope spot (stand here to rope a cliff)
#         ! gear hint sign   ~ thorn pit cell (glider gate; bedrock is put under it)
# Tags surface / under: outdoor rooms. In outdoor areas the top room row only uses 'surface' templates (open sky).
# Tags gate_rope / gate_bomb: path rooms that can only be crossed with that gear (AreaConfig.requiredGear).
#   Gate walls use bedrock (X) so the other gear cannot cheat them; the validator rejects any level whose
#   exit is reachable without the required gear.
# Every generated level is proven passable by LevelValidator, so a bad combination is simply re-rolled.
